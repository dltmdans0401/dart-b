# 1️⃣ 개념 정리 

## 01. 데이터 분석이란

데이터 과학: 통계학, 데이터 분석, 머신러닝, 데이터 마이닝 등을 아우르는 더 큰 개념  
=> 대규모이고, 문제 해결을 위해 최선의 솔루션을 만드는데 초점  
데이터 분석: 의사 결정을 돕기 위해 데이터를 조사, 정제, 변환, 모델링하는 과정  
=> 비교적 소규모이고 의사 결정을 돕기 위한 통찰을 제공하는데 초점  

넓은 의미의 데이터 분석: 데이터 수집, 데이터 처리, 데이터 정제, 모델링  
좁은 의미의 데이터 분석: 기술통계, 탐색적 데이터 분석, 가설검정   

기술통계: 데이터를 정량화하거나 요약하는 기법. ex) 평균, 최소값, 최대값 계산   
탐색적 데이터 분석: 데이터를 시각적으로 표현하여 데이터의 주요 특징을 찾고 분석   
가설검정: 데이터를 기반으로 특정 가정이 합당한지 평가하는 통계 방법  

데이터 마이닝: 데이터에서 패턴 혹은 지식을 추출하는 작업   
머신러닝: 데이터에서 자동으로 규칙을 학습하여 문제를 해결하는 소프트웨어를 만드는 기술  
모델: 머신러닝으로 학습한 소프트웨어 객체  

## 02. 구글 코랩과 주피터 노트북

코랩  
대화형 프로그래밍 환경인 주피터 노트북을 커스터마이징  
텍스트와 프로그램을 자유롭게 작성할 수 있는 파일. 노트북 파일 혹은 i파이노트북파일이라고 부른다.  

코랩: 텍스트 셀: HTML과 마크다운을 혼용해서 사용 가능  
코랩: 코드 셀: 파이썬 사용 가능  
## 03. 이 도서가 얼마나 인기가 좋을까요?

CSV: 콤마로 구분된 텍스트 파일  
=> 한줄이 하나의 레코드이며 레코드는 콤마로 구분된 여러 필드로 구성되어 표 형태를 이룸.   
==> 따라서 일반 텍스트 편집기에서도 열어볼 수 있다.  
데이터 과학에서는 응용 프로그램을 사용해 파일 내용을 봐야하는 엑셀보다는 텍스트인 csv파일 선호  

데이터프레임: 행과 열로 구성된 표 형식의 데이터  
=> 판다스는 csv 파일을 읽어 데이터프레임으로 저장  

시리즈: 동일한 자료형의 데이터를 저장한 1차원 배열의 데이터 구조  

시리즈는 1차원 배열, 데이터 프레임은 2차원 배열과 비슷하다.  
=> 데이터 프레임의 한 속성은 모두 같은 자료형이므로 한 열을 따로 고르면 시리즈이다.   

pandas.read_csv(): csv파일을 데이터 프레임으로 저장하는 함수.  
df.info(): 데이터프레임의 정보를 출력하는 함수  
df.head(): 데이터프레임 상위 5개의 행을 출력하는 함수  
df.describe(): 각 열의 개수, 통계량, 최솟값, 사분위수, 최댓값 등을 출력하는 함수  
df.to_csv(): 데이터 프레임을 csv 파일로 저장하는 함수
